> 项目：Portrait Breakout

> 状态：长期迭代中（仅开发与测试，不发布）

## 设计总目标

把圆环捕手从「只会预测落点、选择内壁或外壁」升级为具备感知、状态判断、控球技能、技能组合与经验优化能力的控制系统。

核心原则：

1. **球的物理真实状态是唯一事实来源。** 表情只是外观；感知层读取真实位置、速度、半径与碰撞几何。
2. **感知与物理分离。** 传感器只读，不直接改变球速、位置、碰撞或随机数序列。
3. **决策与执行分离。** 决策层选择技能，技能层提出动作，物理层按明确规则执行。
4. **生存优先于攻击。** 先保证可接球，再考虑控球与得分。
5. **每次只引入可验证的小改动。** 不同时重写碰撞、瞄准和自动驾驶。
6. **其他四种挡板不受影响。** 圆环专属代码必须受 `shape === 'ring'` 约束。
7. **不以静态代码检查冒充手机实测。** 每个阶段分别记录语法/逻辑检查和用户设备验证。

## 圆环捕手的物理语义（不可随意改写）

- 顶部缺口是逻辑瞄准与进出通道，不是实体墙，也不是球的出生点。
- 球的待发位置仍在圆环内腔底部；发球后从内腔向上穿过缺口。
- 内环壁是软捕捉面：降低法向反弹、保留大部分切向运动，帮助减速和导流。
- 外环壁是硬攻击面：反弹并适度加速，可改变球路。
- 圆环整体移动、接触位置与接触法线可参与甩球和路径控制。
- 缺口通行判断必须扣除球半径与安全余量；球不能通过时应由外壁策略接管。
- 圆环模式下表情包替代球的可见外观，但真实球体及碰撞半径始终存在。

## 系统分层目标

```
RingSensor（只读感知）
    ↓
RingState（球况分类与风险评估）
    ↓
RingPlanner（短期目标与策略选择）
    ↓
RingSkills（基础技能执行）
    ↓
现有圆环物理碰撞
    ↓
RingEvaluator（结果记录与策略调优）
```

### 感知维度

| 传感器 | 输出 | 用途 |
|---|---|---|
| 速度 | 绝对速度、基准速度倍率、速度等级 | 区分低速、常速、高速、极高速 |
| 速度趋势 | 加速度估计、上升/稳定/下降趋势 | 判断球是否正在加速或减速 |
| 方向 | 速度方向、横向/纵向分量 | 判断入射角与运动意图 |
| 空间 | 相对圆心位置、极角、内外壁净距 | 判断球靠近哪一侧壁面 |
| 缺口 | 预计过口时间、预测横向偏移、有效通行余量 | 决定捕捉/通过/外壁接管 |
| 碰撞预测 | 内壁/外壁预计接触时间与位置 | 提前安排挡板移动 |
| 能量 | 速度倍率与动能代理量 | 选择减速、维持或加速 |
| 目标 | 可攻击目标、预计出射路径收益 | 评估控球后是否值得攻击 |

## 基础控球技能规格

| 技能 | 物理手段 | 目标结果 | 主要风险 |
|---|---|---|---|
| 捕捉 / 减速 | 内壁低法向恢复、切向耗散 | 降低速度、稳定球路 | 过度耗散导致球失去有效运动 |
| 加速 | 外壁硬反弹与受控增益 | 增加速度与攻击能量 | 速度过高、难以接管 |
| 甩球 | 控制接触侧、接触点、挡板横向速度与法线 | 主动改变出射方向 | 预测误差、漏接 |
| 移动球 | 内壁切向导流、圆环整体平移、连续接触 | 将球引导至有利位置 | 不必要的横移与振荡 |

技能不能只按名称触发。每次执行都要有前置条件、目标状态、强度限制、冷却/滞回与失败回退。

## 技能组合候选

- 蓄力甩球：内壁减速 → 沿内壁移动定位 → 外壁加速出射。
- 高速卸力：内壁捕捉 → 切向导流 → 重新选择出射通道。
- 反向甩球：预测接触侧 → 移动圆环 → 利用接触法线改变路径。
- 连续加速：外壁反弹 → 重新定位 → 再次外壁攻击（必须设置速度上限）。
- 控球等待：内壁捕捉 → 移动球 → 等待更高价值的出手机会。

以上是设计目标，不代表全部已实现。
