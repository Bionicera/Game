## 2. 用户已经确认的圆环捕手自然原理

这些是产品/玩法约束，不应被重构过程随意改写：

### 2.1 几何与角色
- 球的出生/待发位置仍然是圆环内部底部，不是缺口。
- 顶部缺口是逻辑瞄准与球体进出通道，不是实体墙，不产生虚构碰撞。
- 缺口宽度与球半径、安全余量共同决定是否可通过。
- 内环壁是软接触面；外环壁是硬接触/攻击面。
- 圆环缺口两端逐渐收尖，端部厚度应薄，以减少控制几何复杂度。
- 圆环模式下表情包可替代球的可见图形，但真实球体、位置、速度、半径和碰撞仍存在；表情中心应与真实球心对齐，背景尽可能透明。

### 2.2 两类瞄准模型
- 缺口宽度/净空模型：用于捕捉球、控制球经缺口进出。
- 圆环直径/外壁投影模型：用于攻击球、选择外环接触点。
- 外环壁是**碰撞点投影系统**：目标接触点决定弹射几何。
- 内环壁是**碰撞点角度投影系统**：接触位置取决于当前飞行角度与缺口直径在内环壁上的投影范围。
- 不要把外环简化成“只允许上半部接球”。用户指出：外环接触中点可能让球平移；外环中心点以上才会让球向上弹。下半部死球风险需要真实几何/物理测量，不可只用硬编码遮罩取代模型。

### 2.3 三种核心玩法动作
- **接球**：高速球优先内环壁；低速球可使用外环壁。速度 5 左右只是用户给出的初始参考边界，需通过测试测得内环可可靠接住的最大速度及合理阈值。
- **内环甩球**：内环先接住球，球在内壁左右反弹/震荡；左右震荡至少移动一个圆环半径的距离（按用户定义的行程/周期口径，在实现时需严格区分单程与往返周期）；震荡频率/单位时间内运动频率提供动能；震荡次数越多，出射速度越高。随后圆环向左或向右短程冲刺，球由反方向的内环缺口刀锋端真实接触释放。短冲距离控制甩球角度。极少数内部反弹角度可能造成角度偏差，这是物理结果，不应靠强行重置角度掩盖。
- **外环弹射**：球在外环生存区产生接触点后，圆环短程冲刺，由真实移动接触面/冲量决定球初始出射速度；不得用短冲距离简单直接赋速，需通过接触物理验证映射关系。

### 2.4 生存域
- 用户提出“可生存域完全体”：内环壁全部范围与外环横轴以上范围作为目标可生存区域；约 20% 失败可能来自内环初始飞行速度超过圆环处理能力，导致无法接住/甩出；外环横轴接触点附近存在高死球风险。
- 80%/20% 是用户的初始经验/假设，不是已统计验证的概率。新线程必须通过动力学热图、固定种子批量实验和接触点分布校准，不要把假设写成实测事实。
- 目标优先级：稳定生存/接球 > 控球 > 攻击得分。成功率不稳定的花哨技能不算成功方案。

## 3. 统一物理引擎：已确认的物理原则

### 3.1 物理宪法
- 唯一状态所有者：纳入 PhysicsWorld 的动态对象，其位置、速度由世界/明确的初始化与规则效果接口管理，策略层不得旁路写入。
- 几何与响应分离：Collider 只输出几何接触；Solver 根据 Contact、材质、质量和接触表面速度求冲量；规则层处理得分、耐久、生命、掉落和关卡。
- 先求接触点相对速度，再求冲量。
- 挡板/圆环第一阶段作为运动学刚体：驱动器给定运动，但其接触表面速度参与碰撞，驱动器做功单独记账。
- 静态墙/普通静态砖块/弹力柱可作为静态碰撞体。
- 非刚体规则实体（落砖、俯冲敌机、蛇头火箭、粒子等）不必一开始强行塞入刚体求解器；可以先共享受控时间步与事件契约。
- 发球、减速道具、诅咒重力、外环游戏增益等必须通过明确命名的规则效果接口，不得伪装成自然碰撞。
- 生产迁移可回滚；旧物理实现保留作基线。

### 3.2 单位/质量
- 长度：CSS px；时间：s；速度：px/s；加速度：px/s²。
- 质量是游戏质量单位，不需要等同现实公斤，但必须正、可比较并参与冲量方程。
- 第一版可将球质量归一化为 1；额外球需明确是否同质量。静态/运动学边界 inverseMass=0。
- 不应因为生产旧球没有 mass 字段就断言不能模拟；关键是新内核显式质量并一致使用。

### 3.3 接触公式约定
- 法线 `n` 从 B 指向 A。
- 接触点相对速度 `u = vA_contact - vB_contact`。
- 法向速度 `un = dot(u,n)`；仅当 `un < 0`（正在接近）时施加法向冲量。
- `jN = -(1+e) * un / (invMassA + invMassB)`。
- 切线 `t=(-n.y,n.x)`，`ut=dot(u,t)`。
- 库仑摩擦候选：`jT=clamp(-ut/(invMassA+invMassB), -mu*jN, +mu*jN)`。
- A 施加 `+J`，B 施加 `-J`。
- 静态/运动学边界 inverseMass=0，不被碰撞反冲改变，但运动学表面速度影响相对速度。
- 对单一法向冲量，无旋转接触，恢复耗散 `D=0.5*mEff*(1-e²)*un²`。
- 运动学边界做功和恢复/摩擦耗散分开记账；不能把驱动做功直接等同球动能变化。
- 位置穿透修正与速度冲量是两件事，分别处理。
- 接触分离时不重复施加冲量。
- 第一版不启用刚体旋转，未来若需要再引入惯量/角速度与接触点速度 `v + ω×r`。

### 3.4 时间步
- 生产现状：requestAnimationFrame 的帧 dt 上限约 0.033s；球通过按速度估算的可变子步推进，曲线接触内部还有扫掠采样；尚无统一固定步累积器。
- 新内核 FixedStepRunner 默认实验参数 1/120s、最多 4 子步，但**不是已经验证的生产决定**。
- 新 Runner 保留追赶 backlog，不静默丢弃；暂停不累计时间。
- 后续需比较 1/90、1/120、1/180，评估性能、碰撞稳定性和第一关结果后再定案。

- 物理引擎不能静默丢弃 backlog；同时需评估长 backlog 对实时游戏的处理策略（明确暂停/降速/上限策略并遥测）。

### 第四步：生产迁移（只有 P2/P3 达到退出门槛后）
顺序固定：
1. 静态墙壁；
2. 普通挡板；
3. 砖块；
4. 圆环内外壁；
5. 多球与特殊场景。
每一类都先建基线、开关/回滚、配对场景测试、浏览器 smoke，再替换；不一次性推倒生产路径。

### 第五步：圆环捕手与整关验收
- 移除甩球直接赋速；震荡真实运动与运动学接触面做功传能。
- 外环短冲弹射也通过真实接触冲量。
- 构建接触点动力学热图/可生存域：记录接触角、速度、接触法线、冲量、出射方向、是否回到底部/死球/得分。
- 统计用户提出的 80/20 假设是否成立，测量内环最大可接速度和外环横轴风险带。
- 第一关固定种子配对 A/B + 多个新种子泛化，报告样本量、胜率、置信区间、失败原因；稳定通关是验收门槛。

## 8. 施工记录规范

每次实质提交后必须更新 `docs/RING_CATCHER_ROADMAP.md`：
- 日期/阶段；
- 本轮目标；
- 变更文件；
- 新增能力；
- 测试命令/测试数量；
- CI Actions run 链接与真实状态；
- 生产代码是否变更；
- 未完成项/风险；
- 下一步。
- 只把有证据通过的项目标成 [x]。
- 不把“实现了接口”写成“物理功能完成”。
- 不把参考测试写成生产关卡测试。
- 不把浏览器 smoke 写成手机测试。
- 不发布、不部署。

然后立即开始查仓库和施工，不要只给计划不做事。
